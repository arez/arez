# Arez

Arez is a reactive state management library for Java and J2CL applications.

Run commands from the repository root:

- Focused JVM tests: `bazel test //:jvm_tests`.
- Full local/CI gate before submitting: `tools/check.sh`.

Read the guidance for the work you are doing:

- Java changes: [Java conventions](docs/agents/java.md).
- Source, fixture, test, or build changes: [build and testing](docs/agents/build-and-test.md).
- Commits, PRs, changelogs, API docs, packaging, or releases:
  [contributions and releases](docs/agents/contributing.md).
